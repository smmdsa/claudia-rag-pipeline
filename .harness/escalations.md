# Escalations — what the agent cannot decide

Two levels sit above the agent: the paradigm (what we assume this work is) and the
objective of the system. When an analysis points there, the agent edits nothing. It
writes the observation here, with the measurement, and stops.

Why a file and not a conversation: a self-editing system that only reaches the low
levels converges to the local maximum of the current paradigm. It optimises up to the
ceiling of its assumptions and stays there. The user moves that ceiling. The agent
only points at it. Without a place to point, the pointing is lost in the scroll of a
session.

Format: `python3 -m harness escalate --title ... --observed ... --level ... --decision-needed ...`
appends an entry: the date, what was observed with its measurement, which level it
touches, and the decision that is needed. Never the decision taken. The user writes
the decision under the entry.
