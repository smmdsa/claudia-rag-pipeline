# Project conventions

Languages: python, shell, javascript.

1. Read the rules file that `python3 -m harness doctor --json` names as `rules_path`.
2. Follow the Glossary. One word, one meaning.
3. Add no dependency without a measured need and the user's approval.
4. Run the test command of the repository before you report a change as done.
